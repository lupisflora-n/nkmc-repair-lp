# LP用アセットの保管ルール

このディレクトリは公開LPが実際に使用する画像・アイコンを置く場所です。制作元ファイルや確認用資料は `design/` や `docs/` に置き、公開用フォルダへ混ぜません。

- `brand/<brand-name>/logos/svg/`：ブランド別のアウトライン化SVG。拡大しても劣化しません。
- `brand/<brand-name>/logos/png/`：背景透過のPNG。
- `brand/<brand-name>/icons/`：SNS用画像、favicon。
- `ui/icons/`：ブランドに属さない共通UIアイコン（必要になったら作成）。
- `illustrations/`：説明イラスト等（必要になったら作成）。
- `cases/`：施工事例の原写真。**一切加工・変換せず**、元ファイルをそのまま使用。
- `photography/`：施工事例以外の写真（必要時に作成。利用条件を確認）。

屋号ごとに素材を混ぜず、文字は小文字・ハイフンのファイル名を使用します。公開LPへ実際に組み込む前に`site/content.json`の参照先と使用条件を確認してください。
