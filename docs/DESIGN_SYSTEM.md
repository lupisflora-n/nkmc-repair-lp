# LIBRIGHT LPのデザイン

基準: `design/brand/libright/brand-guide.txt` と正式ロゴ「仕上げの一筆」。

## 色と形

- 黒 `#151515` と白 `#FFFFFF` を基調にする。
- 黄色 `#F3C63A` を地域の帯、補修後ラベル、相談ボタン等のアクセントに使う。
- 赤 `#C54136` は見出しの小さな目印と番号に使い、面積を抑える。
- 角丸や装飾的な影は使わず、直角・罫線・余白で情報を整理する。
- 太めの日本語見出しと小さな英字ラベルを組み合わせる。本文はシステム書体とし、ロゴの文字はアウトライン済みの正式SVGを使う。

## ロゴ

- ヘッダー: `horizontal-jp-color.svg`。PC246px、スマホ220px。元の縦横比を保つ。
- 冒頭: `symbol-color.svg` をそのまま使用。十分な余白をとり、写真の代用品とは扱わない。
- フッター: 黒背景に `horizontal-jp-white.svg`。幅230px／スマホ220px。
- ブラウザタブ: 専用の `favicon.svg` と32px PNG。
- 色変更、変形、切り抜き、シャドウ等の画像効果は加えない。

## ページの構成

1. 法人向けの対応内容と相談導線、ブランドの一文、正式シンボル。
2. 黄色の帯で対応地域と部材を提示。
3. 施工事例は1例ずつ、部位と説明・前後写真の組で表示。
4. 黒背景のサービス欄を3区分とし、まとめ補修・継続取引・緊急相談を示す。
5. 短い原点の物語、現在の実務とTRC/RBSとの関係、現場で大切にする3項目、地域、施工の流れ、FAQへ続ける。関係の紹介はNさんの実務を主文に、TRCとRBSの紹介を独立した下段の枠へ置く（最終未確認時は確認版のみ）。ブランド詳細と語源は開閉式にし、ブランドの主見出しは常に見せる。
6. 黒背景・黄色ボタンの相談欄と白抜きロゴのフッターで締める。

写真はユーザーの無加工ルールを優先する。写真そのものにロゴ色を重ねたり、形に合わせて切り抜いたりしない。前後の撮影条件が異なることも説明する。

## プレビュー

`python scripts/build.py --mode review` で単体HTMLと通常の静的サイトを生成する。ブランド素材は単体HTMLのみdata URIへ可逆に格納し、元素材は変更しない。
デザイン変更時は320/390/768/1440pxでロゴ読み込み、縦横比、横方向のはみ出し、相談導線を確認する。

## v0.4の配置指定

ユーザー編集原稿により、冒頭左の対象表示とブランドの補助文を削除。ブランド見出しと原点の本文をマーク欄へ移動。マーク自体の色・形を変えず、表示サイズを160px（スマホ120px）に調整して文章の余白を確保した。後段の物語欄は小見出しと詳細開閉で残し、移動本文は重複表示しない。
