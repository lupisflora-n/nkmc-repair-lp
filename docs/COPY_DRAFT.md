# 法人向けLP 構成・原稿たたき台 v0.1

更新日: 2026-10-29
状態: 内部確認用の初稿。公開用の確定原稿ではない。
対象: 工務店・建築会社の担当者。継続取引の相談を第一目的とする。

`【内部メモ】` は制作指示であり、公開画面に出さない。未確認の料金、即応条件、事例、第三者の評価を補っていない。

## 1. 冒頭

対象表示:
工務店・建築会社の皆さまへ

主見出し案:
引渡し前のキズ補修から、急な補修のご相談まで。

本文案:
木部・フローリング・アルミサッシのキズ補修は、リブライトへ。
千葉県を中心に、関東エリアの現場に対応しています。
引渡し前のまとめ補修、継続的なお取引のご相談を承ります。

主なボタン:
現場の補修を相談する

副リンク:
施工前後の写真を見る

ブランドの補助文:
傷を直す。その先の、晴れやかな暮らしまで。

【内部メモ】ロゴと主写真は受領後に差し込む。緊急依頼は「相談可」を伝え、即日・24時間・最短時間は表示しない。主ボタンはInstagramプロフィール等の実際に機能する導線を確認後に設定する。

## 2. 施工前後を写真で確認

【内部メモ】ユーザー指示により、写真の編集・変更は禁止。元ファイルのまま、元の縦横比と写真全体を保って表示する。前後ラベルと説明文は写真の外側に配置する。

見出し:
補修前と補修後を、写真でご覧ください。

本文案:
部材やキズの状態とあわせて、補修前後の変化をご紹介します。

事例01の仮原稿:
縦枠の欠け補修
「室内建具の縦枠に生じた欠けの補修事例です。」

事例02の仮原稿:
上枠の角・接合部の補修
「室内建具の上枠の角・接合部に関する補修事例です。」

事例03の仮原稿:
扉下端の欠け補修
「木目調の扉の下端に見られる欠け・傷の補修事例です。」

【内部メモ】3例とも会話内で確認した計6画像からの仮原稿。詳細は `PHOTO_REGISTER.md`。撮影角度や明るさ、縦横比が異なるため原画像全体を横並びで示し、比較スライダーで重ねない。部位と作業内容の正式な確認、元画像取得、掲載条件の確認後に公開する。架空事例や生成した施工写真は入れない。

## 3. 相談できる仕事

見出し:
引渡し前のまとめ補修も、急なキズのご相談も。

項目1:
引渡し前のまとめ補修
現場内にある複数のキズについて、まとめてご相談いただけます。

項目2:
継続的な現場のご依頼
今後の現場での補修先をお探しの工務店・建築会社さまも、お問い合わせください。

項目3:
緊急補修のご相談
お急ぎの場合は、現場の地域、キズの状態、ご希望の日時をお知らせください。
対応できるかを含め、日程をご相談します。

対応部材:
木部／フローリング／アルミサッシ

【内部メモ】各項目はユーザー回答の範囲で作成。構造材の修繕、設備工事、塗装全般、家具全般など、対象外の工事へ勝手に広げない。対応できない傷や素材の詳細はnさん確認後に追記する。

## 4. リブライトについて

見出し:
傷を直す。その先の、晴れやかな暮らしまで。

工務店・建築会社向けの接続文:
引渡しの先にある、晴れやかな暮らしを支えるために。

紹介文（ユーザー提供の対外コンセプト）:
住まいについた傷だけでなく、その傷を見るたびに生まれる気がかりにも目を向ける。
丁寧な補修で住まいの本来の美しさを取り戻し、安心して毎日を過ごせるように。
かつて補修技術に感動した人が、今度はその技術で人に喜びを届けていく。

屋号の説明:
フランス語の「libre（自由な）」と、英語の「bright（明るい・輝かしい）」。LIBRIGHTは、住まいの傷への気がかりを手放し、晴れやかな暮らしへ向かうお手伝いを目指しています。

【内部メモ】コンセプト本文はユーザーが提示して組み込みを指示した文章。創業者本人の発言の引用としては扱わない。私的な創業動機は公開文面へ転記しない。人物写真、公開名、事業者情報は未受領。
【内部メモ】TRCは任意の紹介枠。関係・掲載条件・同社の紹介文と公式案内先が整ってから別途構成し、nさんの実績として一括計上しない。

## 5. 地域・料金

見出し:
千葉県を中心に、関東エリアへ。

地域の本文案:
ご相談の際は、現場の市区町村とご希望の日程をお知らせください。

【内部メモ】市区町村の範囲、遠方対応、出張費は確認待ち。関東全域で一律の条件という意味にしない。
【内部メモ】料金セクションはnさん確認後に作成。最低料金、金額の単位、税、出張費、見積もりの条件、追加費用の条件をまとめる。数値が未確定の間は非表示にできる設計にする。「見積もり無料」は未確認のため使わない。

## 6. ご相談から施工まで

見出し:
まずは、現場の状況をお知らせください。

手順の原稿案:
1. ご相談
   現場の地域、ご希望の日程、キズの写真や箇所数をお知らせください。
2. 内容の確認・お見積もり
   補修内容と条件を確認し、お見積もりをご案内します。
3. 日程の調整・施工
   内容と日程を確認のうえ、施工へ進みます。
4. 仕上がりの確認
   施工した箇所の仕上がりをご確認いただきます。

【内部メモ】実際の業務手順はnさん確認待ち。写真だけで見積もれると断定しない。返信時間、支払条件、保証、キャンセル条件は未確認。

## 7. 問い合わせ

見出し:
現場の補修先をお探しでしたら、ご相談ください。

本文案:
引渡し前のまとめ補修から、継続的な現場のご依頼まで。
ご相談の際は、次の内容が分かると確認を進めやすくなります。

- 会社名・ご担当者名
- 現場の市区町村
- 希望する日程・引渡し予定日
- キズの箇所数と写真（全体が分かる写真・近くからの写真）

主なボタン:
Instagramで補修を相談する

添える文の案:
一般のお客様からの住宅のキズ補修も、ご相談いただけます。

DMの文面例:
会社名・担当者名：
現場の市区町村：
希望日程・引渡し予定日：
キズの箇所数・気になる点：
（全体とキズの写真を添付）

【内部メモ】Instagram DM採用を確定した後に、実際に送れる経路と操作を確認する。予約完了・注文成立と誤認させる案内はしない。一般のお客様には会社名・担当者名を必須にしない。
